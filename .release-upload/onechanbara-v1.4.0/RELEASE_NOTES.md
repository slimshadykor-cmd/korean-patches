# 오네찬바라 볼텍스 한글패치 v1.4.0 — 로딩 대폭 개선

**한글화: 슬림쉐이디**

사용자 플레이 확인을 마친 로딩 개선을 기존 한글화에 통합했습니다. 특정 챕터·난이도에 한정하지 않고 공통 로딩 처리에 적용됩니다. 이전 한글화와 영상 자막, 대사·여신상·팔찌·시스템 문구 수정을 모두 포함한 누적 패치입니다.

## 다운로드 및 적용

[**Onechanbara_ISO_Korean_v1.4.0_Release.zip 받기**](https://github.com/slimshadykor-cmd/korean-patches/releases/download/onechanbara-v1.4.0/Onechanbara_ISO_Korean_v1.4.0_Release.zip)

1. 게임을 종료하고 ZIP을 풉니다.
2. `Onechanbara_ISO_Korean_v1.4.0.exe`를 실행합니다.
3. **일본판 원본 또는 현재 사용 중인 지원 한글판 ISO**를 선택합니다.
4. 새 ISO의 저장 위치와 이름을 지정합니다.
5. 완료 후 새 ISO를 Xenia에서 불러옵니다.

**기존 v1.3.0 ISO에 바로 적용할 수 있습니다.** 이전 패치나 시험판을 순서대로 설치할 필요는 없습니다. 입력 ISO는 보존하고 새 ISO를 만듭니다. 기존 게임 내 세이브도 그대로 사용합니다.

정식 v1.2.2~v1.3.0, 기존 지원 GoddessFix1·Loading Test01 적용판과 v1.3.0 기반 Loading Test02~04도 지원합니다. Windows 10/11 64비트와 .NET Framework 4.8, 새 ISO와 약 500MB의 임시 저장 공간이 필요합니다.

## 변경 및 확인 범위

- 시험판 04의 로딩 개선을 정식판에 통합했습니다. 게임 실행파일은 사용자 확인본과 SHA-256까지 동일합니다.
- 타이틀 화면 왼쪽 아래와 패처에 **v1.4.0**을 표시합니다.
- 기존 158개 패치 대상 중 로딩 실행파일·타이틀 버전 표시 외 156개를 보존했습니다.
- 게임 전체 속도·프레임 제한·세이브 방식은 유지합니다. 입모양·대화 동작의 추가 수정은 이번에 포함하지 않았습니다.
- 원본·v1.3.0·Test02~04 자료로 구성한 ISO 시험 구조에서 배포 EXE의 적용 결과, 입력 보존, 재적용·잘못된 파일 거부를 확인했습니다.

사용자가 실제 플레이에서 로딩 개선을 확인했습니다. 전 챕터·전 난이도를 직접 완주한 검수는 아니며, PC·에뮬레이터·구간에 따라 체감 차이가 있습니다.
