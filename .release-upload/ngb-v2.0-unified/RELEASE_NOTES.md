## 설치

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe** 실행 → 지원하는 원본 또는 기존 공용 한글 ISO 선택.
3. **새 한글 XISO 만들기**를 누릅니다.
4. 사용 중인 에뮬레이터를 완전히 종료하고 새 **NGB_Korean_v2.0.xiso.iso**로 부팅합니다.
