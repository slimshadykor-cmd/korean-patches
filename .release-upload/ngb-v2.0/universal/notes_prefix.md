## v2.1 공용 패처 수정

- 사용할 기기를 고르는 절차와 기기별 출력 분기를 제거했습니다. 구엑박·Xbox 360·xemu·하쿠X에 사용할 게임 파일을 따로 나누지 않습니다.
- 기존 v2.0의 한글화·기능과 v2.1의 Xbox 360 부팅·폭풍 진행·설명문 겹침 대응을 포함합니다.
- **기존 v2.1에서 'Xbox 360 / 오로라'를 선택해 만든 게임 파일은 이번 공용 결과물과 동일합니다. 다시 패치할 필요가 없습니다.**
- '구엑박 / xemu'를 선택했던 기존 v2.1, v2.0, Test1~4도 공용 결과물로 변환할 수 있습니다.

## 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제하고 **NGB_Korean_Patch.exe**를 실행합니다.
2. 지원하는 원본·기존 한글판 ISO/XISO 또는 게임 폴더의 **default.xbe**를 선택합니다.
3. **한글패치 적용 — 새 파일 만들기**를 누릅니다.
4. ISO 입력은 새 XISO를 사용합니다. default.xbe 입력은 생성된 **적용방법.txt**를 따라 교체 파일을 해당 게임 폴더에 적용합니다. 출력 폴더 자체는 게임 전체가 아닙니다.

Japan/Korea (En,Ja)판과 기존 패처가 지원하던 한글판을 지원합니다. default.xbe 입력에는 같은 폴더의 게임 자료가 필요합니다. 원본·세이브·HDD를 덮어쓰거나 변환하지 않습니다. 별도 Python 설치나 인터넷 연결은 필요 없습니다.

## 확인한 범위

- 원본·기존 한글판·Test1~4·기존 v2.1의 공용 변환, 폴더 출력, 일반 ISO/XISO, 재적용과 손상 입력 거부 검사를 통과했습니다.
- 메뉴·의상·저장 표시용 자원 처리의 x86 코드 검사 67개 사례와 30회 전환을 통과했습니다. Pentium III CPU 모델에서도 확인했으며 파일·그래픽 API는 모의 처리한 검사입니다. 실제 플레이 검사와 구분합니다.
- 한글 좌표는 v2.0과 동일합니다. 번역·그림·블랙/폭풍 기능은 보존합니다.
- 공용 실행파일은 기존 v2.1 Xbox 360용과 바이트 단위로 같습니다. 동일 파일로 PC **Xenia Edge + XeFu3**에서 블랙·폭풍 기본/흰색 의상, 첫 스테이지, 이동·한글 메뉴를 확인한 기록을 재사용했습니다.
- **이번 공용 실행파일의 xemu·하쿠X 실제 플레이와 구엑박·Xbox 360 실기 확인은 아직 완료하지 않았습니다.** v2.0의 기존 정상 제보를 이번 실행파일의 실제 플레이 확인으로 확대하지 않습니다. 전 챕터·모든 저장 조합 완주도 미확인입니다.
- 패처는 Linux Tk에서 버튼 배치와 기기 선택 제거를 검사했습니다. Windows 실행파일·동봉 런타임은 기존 배포본 그대로이며 이번 환경에서 Windows로 실행하지 않았습니다.

상세 기록은 ZIP의 `audit/verification.json`에 있습니다.
