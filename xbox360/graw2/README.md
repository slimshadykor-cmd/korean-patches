## 준비

- 사용 중인 Windows PC와 Xenia Canary의 `xenia_canary.exe`
- 지원하는 Xbox 360판의 수정하지 않은 원본 ISO
- 원본과 별도로 새 ISO를 저장할 충분한 디스크 공간

게임 원본과 Xenia 본체는 포함하지 않습니다. 실기용 배포본이 아닙니다.
지원하지 않는 원본이나 이미 수정된 ISO는 검사에서 거부될 수 있습니다.

## 처음 설치하기

1. Xenia를 종료한 뒤 ZIP 전체를 새 폴더에 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
2. `GRAW2-START.cmd`를 더블클릭합니다.
3. 파일 선택 창에서 평소 사용하는 `xenia_canary.exe`를 고르고 **열기**를 누릅니다.
4. 패치 화면에서 원본 ISO를 고르고, 새 한글 ISO를 저장할 위치를 지정합니다. 원본과 다른 파일을 선택합니다.
5. **새 한글 ISO 만들기**를 누르고 완료 안내를 기다립니다.
6. 기본 체크 상태에서는 완료 후 게임과 자막이 실행되고 바탕화면 바로가기가 만들어집니다.
7. 다음부터는 만들어진 **고스트리콘 2** 바탕화면 바로가기로 실행합니다.

안내 글자의 광채는 설치 화면에서 선택할 수 있으며 기본값은 약한 광채입니다.
자막 실행기를 따로 켜거나 과거 수정 패치를 추가로 적용할 필요가 없습니다.

## 기존 사용자

버전 표기까지 갱신하려면 원본 ISO에서 새 한글 ISO를 만든 뒤 새 바로가기를 사용하세요.

새 버전 확인 전까지 기존 정상 ISO와 패치 ZIP은 보관하세요.
원본 ISO, Xenia 실행파일, 공용 설정과 기존 저장 데이터는 덮어쓰지 않습니다.
이 패치의 전용 실행 자료는 선택한 Xenia 아래 `config/GRAW2`에서 관리합니다.
