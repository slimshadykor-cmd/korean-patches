## 적용 방법

1. 다운로드한 ZIP을 원하는 폴더에 풉니다.
2. `Onechanbara_ISO_Korean_v1.2.6.exe`를 실행합니다.
3. **ISO 선택** 버튼을 누르고 ISO를 선택합니다.
4. 한글판 ISO를 저장할 위치와 새 파일 이름을 지정합니다.
5. 완료 메시지가 나오면 Xenia에서 생성된 ISO를 직접 불러옵니다.

게임 ISO를 압축 해제할 필요는 없습니다. 원본 ISO는 보존되며 별도의 한글판 ISO가 생성됩니다.

기존 v1.2.2·v1.2.3·v1.2.4·v1.2.5 사용자는 해당 ISO에 이번 패치를 한 번 적용하면 됩니다.

## v1.2.6 변경 사항

모든 구역에서 사용하는 공통 장소명·모드명 96곳(원문 31종)을 추가 한글화했습니다. 거리·병원·연구 시설·비행정·서바이벌·연습장 등의 표시를 수정했으며, 메인 화면에서 패치 버전을 확인할 수 있습니다.

v1.2.5까지의 수정이 모두 포함된 누적 패치입니다. 캐릭터 꾸미기 설명 240곳과 뷰 모드 표시 이름 1,183곳, 미션 안내문 및 엔딩 첫 화면 한글화도 포함됩니다.

## 포함된 수정

- 게임 대사, 화자 이름, 메뉴 및 관련 문구 한글화
- 대사 출력 중 잘못된 글자가 보이는 현상 수정
- 열쇠 사용 확인 문구 수정
- 영상 자막 및 홍보 영상 마지막 부제 수정

공통 장소명 표와 미션 안내, 기존 대사 및 글꼴을 파일 기준으로 검사했습니다. 원본 자료와 v1.2.5 자료를 사용한 ISO 구조에서 패치 적용 결과와 원본 보존을 확인했습니다. 이번 버전으로 제니아에서 엔딩까지 직접 플레이한 검수는 완료하지 않았습니다.

간단한 영어 표기는 일부 유지하며, 배경 간판·장식 글씨와 제작진 실명은 원문을 유지합니다.

원본 게임 ISO와 Xenia는 포함되어 있지 않습니다.
