## 준비물

- 오네찬바라 볼텍스 일본판 원본 ISO 또는 정식 v1.2.2·v1.2.3·v1.2.4 패치가 적용된 ISO
- Windows 64비트 / .NET Framework 4.8
- 출력 ISO를 저장할 여유 공간 및 약 500MB의 임시 여유 공간
- Xenia

## 적용 방법

1. 다운로드한 ZIP을 원하는 폴더에 풉니다.
2. `Onechanbara_ISO_Korean_v1.2.5.exe`를 실행합니다.
3. **ISO 선택** 버튼을 누르고 ISO를 선택합니다.
4. 한글판 ISO를 저장할 위치와 새 파일 이름을 지정합니다.
5. 완료 메시지가 나오면 Xenia에서 생성된 ISO를 직접 불러옵니다.

게임 ISO를 압축 해제할 필요는 없습니다. 원본 ISO는 보존되며 별도의 한글판 ISO가 생성됩니다.

기존 v1.2.2·v1.2.3·v1.2.4 사용자는 해당 ISO에 이번 패치를 한 번 적용하면 됩니다.

## v1.2.5 변경 사항

캐릭터 꾸미기 설명 240곳과 뷰 모드 표시 이름 1,183곳을 추가 한글화했습니다.

총 86개 메뉴 파일의 표시 문자열 1,423곳(원문 450종)을 수정했습니다. 이전 미션 안내문 수정과 엔딩 첫 화면 한글화도 포함합니다.

## 포함된 수정

- 게임 대사, 화자 이름, 메뉴 및 관련 문구 한글화
- 대사 출력 중 잘못된 글자가 보이는 현상 수정
- 열쇠 사용 확인 문구 수정
- 영상 자막 및 홍보 영상 마지막 부제 수정

파일 기준 번역·표시 위치·패치 적용 검사를 진행했습니다. 제니아에서 엔딩까지 직접 플레이한 검수는 완료하지 않았습니다.

간단한 영어 표기는 일부 유지하며, 배경 간판·장식 글씨와 제작진 실명은 원문을 유지합니다.

원본 게임 ISO와 Xenia는 포함되어 있지 않습니다.
