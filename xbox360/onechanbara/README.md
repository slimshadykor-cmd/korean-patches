# 오네찬바라 볼텍스 일본판 한글패치 v1.6.1

**한글화 슬림쉐이디**

기존 한글화·영상 자막·로딩 개선·전용 Vulkan 실행을 포함한 통합본입니다. 이번 수정은 **오네찬바라 세이브를 원래 저장 위치에서 사용하도록 연결하는 것**입니다. 그래픽·프레임·게임 속도·콤보 설정은 v1.6.0에서 바꾸지 않았습니다.

## 바탕화면 바로가기 · 아야 아이콘 추가

실행 연결을 완료하면 현재 Windows 계정의 바탕화면에 **오네찬바라** 바로가기를 생성합니다. 게임 원본에 포함된 **아야 얼굴 그림**을 사용합니다. 이미 같은 전용 바로가기가 있으면 하나만 갱신합니다. 아이콘 파일은 `config\Onechanbara\Onechanbara.ico`에 보관하며, 바탕화면에 아이콘 파일을 따로 풀지 않습니다.

이미 한글 ISO가 있으면 아래쪽 **세이브 연결·바탕화면 바로가기** 버튼으로 연결만 다시 진행하세요. ISO 패치 데이터와 세이브·의상 처리, 그래픽 설정은 직전 수정본과 같습니다. 실행 도구 내부 빌드는 **1.6.1.2**입니다.

## 2026-11-07 실행 연결 오류 수정

`기존 자동 로그인 프로필을 찾지 못했습니다. 슬롯 0` 오류를 일으킨 저장 경로 판별을 수정했습니다. 검증 대상 Windows 빌드는 `portable.txt` 없이도 실행 폴더를 기본 위치로 사용합니다. 수정 도구의 내부 빌드는 **1.6.1.2**이며, 게임 패치 버전은 **v1.6.1**입니다.

**이미 생성한 ISO는 다시 만들지 마세요.** 아래쪽 실행 연결 버튼으로 다시 연결하면 됩니다. 공통·전용 설정과 캐시가 없는 첫 설치 조건도 별도로 검사했습니다. 원래 `content` 폴더의 세이브·의상 데이터·프로필은 보존하세요. 이전 전용 폴더의 `content`도 최근 저장이 있을 수 있으므로 확인 전 삭제하지 마세요.

기존 링크를 유지하기 위해 마지막 배포 페이지를 갱신했습니다. 주소의 `onechanbara-v1.4.0`은 기존 태그이며, 현재 패치와 첨부 파일은 **v1.6.1**입니다.

## 이미 v1.6.0을 사용 중이라면

1. 제니아를 모두 종료하고 ZIP을 풉니다.
2. `Onechanbara_Korean_v1.6.1.exe`를 실행합니다.
3. 아래쪽 **기존 v1.6.0 / v1.6.1 ISO — 세이브 연결·바탕화면 바로가기** 버튼을 누릅니다.
4. 지금 쓰는 한글 ISO와 기존 `xenia_canary.exe`를 선택합니다.
5. 양쪽 세이브가 다를 때만 **전용 폴더의 진행 상황 가져오기 / 기존 위치의 진행 상황 유지 / 취소** 중 선택합니다.
6. 완료 후 기존 바탕화면 **오네찬바라** 바로가기로 실행합니다.

**ISO를 다시 만들 필요는 없습니다.** 실행 연결만 갱신한 기존 ISO의 타이틀 표시는 v1.6.0 그대로입니다. 새 ISO를 만들면 타이틀 표기도 v1.6.1로 바뀝니다.

## 처음 패치하는 경우

첫 번째 **한글패치 적용 — 새 ISO 만들기** 버튼에서 일본판 원본 또는 지원하는 기존 한글 ISO를 선택합니다. 입력 파일은 보존하고 새 ISO를 만듭니다. 이전 패치를 순서대로 설치할 필요가 없습니다. 전용 실행 연결을 사용할 때 기존 `xenia_canary.exe`를 선택합니다.

## 세이브와 다른 게임 보호

| 항목 | v1.6.1 동작 |
|---|---|
| 오네찬바라 세이브 | 원래 `content\<프로필 ID>\445007D2\00000001` 사용 |
| 저장 이름 | `game00` 게임 진행 / `costume00` 의상 데이터; 환경에 따라 파일 또는 폴더로 표시 |
| 전용 설정·캐시·로그·프로필·DLC | 계속 `config\Onechanbara` 안에 분리 |
| 원본 Xenia EXE·공통 TOML·다른 게임 설정 | 수정하지 않음 |
| 다른 게임 세이브·원래 프로필 | 복구 대상으로 삼거나 덮어쓰지 않음 |
| 이전 세이브 | `config\Onechanbara\save_backups` 안에 양쪽 보관 |

오네찬바라의 **저장 데이터 유형 `00000001` 폴더만** 원래 위치에 연결합니다. 전용 폴더의 해당 경로로 저장해도 실제 데이터는 원래 세이브 위치에 기록됩니다. 저장 복사본끼리 매번 동기화하는 방식이 아닙니다.

기존 저장과 전용 저장이 다르면 시각만 보고 어느 쪽이 최신인지 단정하지 않습니다. 명시적으로 선택한 뒤 백업·복사를 검사합니다. 연결 실패 시 진행한 저장 변경과 전용 등록 파일을 되돌립니다. 복구 백업은 확인 전에 지우지 마세요.

공통 TOML은 원래 `content_root` 경로 확인에만 읽습니다. 공통 그래픽 설정을 가져오거나 잠깐 바꿨다가 복원하지 않습니다. 새 프로필로 바꾼 경우 실행 연결을 다시 진행하세요.

## 유지한 내용

- 기존 한글화·영상 자막·로딩 개선 유지. 게임 데이터 158개 중 새로 바뀐 것은 타이틀 버전 이미지 1개입니다.
- Vulkan / FSI / 2x2 및 VSync 구성 유지. 기존 전용 비동기 셰이더 설정과 캐시 유지.
- 추가 FPS 해제, 게임 가속, 콤보 판정 변경 없음. 미확인 프레임·콤보 문제는 이번 수정 대상에 넣지 않았습니다.
- 전용 EXE는 원본의 동일 사본이며 원본 EXE를 덮어쓰지 않습니다.
- 오네찬바라 바로가기는 같은 이름으로 갱신합니다. 다른 대상의 바로가기는 덮어쓰지 않습니다.

## 실행 조건·검수 범위

Windows 10/11 64비트, .NET Framework 4.8, Windows PowerShell 5.1. 전용 폴더는 Windows 폴더 연결을 지원하는 로컬 드라이브(NTFS 등)에 있어야 합니다. 지원 여부는 세이브 변경 전에 검사합니다.

전용 실행은 사용자 확인 빌드 **Xenia Canary b083312b8 (2026-10-02)**의 EXE 해시를 검사합니다. 다른 빌드에서는 연결 체크를 해제하고 한글 ISO만 만들 수 있습니다. Xenia 배포본은 포함하지 않습니다. 기존 Xenia 프로필이 필요하며, 별도 명령줄 저장 경로는 자동 판정 대상이 아닙니다.

세이브 연결·양쪽 저장 보존·다른 게임 파일 보존·실패 복구 **기본 19개 + 첫 설치 5개 + 바로가기·아이콘 8개 자동 검사**, 배포 EXE의 실제 ISO 처리와 v1.6.0/1.6.1 연결 검사를 통과했습니다. **실제 Windows의 새 폴더 연결과 게임 저장·불러오기는 아직 실행 검증하지 않았습니다.** 자동 검사는 Linux에서 Windows COM/프로세스를 대역으로, junction을 실제 POSIX 심볼릭 링크로 대체했습니다. 세부 범위는 ZIP의 `검수결과.txt`에 적었습니다.

게임 ISO, Xenia, 개인 세이브와 트레이너는 포함하지 않습니다.
