ZIP에는 패치 EXE, 사용 안내문, 원본 ISO 해시 안내가 들어 있습니다.

## 원본 및 기존 한글판 지원

같은 EXE로 아래 ISO를 v1.2.8로 만들 수 있습니다.

- 일본판 원본 ISO
- 정식 v1.2.2~v1.2.7 한글판 ISO
- 위 한글판에 별도 여신상 수정 1(GoddessFix1)을 적용한 ISO

새 사용자는 원본에 한 번만 적용하면 됩니다. 기존 사용자는 현재 사용 중인 지원 한글판에 한 번 적용하면 되며, 이전 패치를 다시 순서대로 적용할 필요가 없습니다.

## 준비물 및 적용 방법

Windows 64비트 / .NET Framework 4.8, 새 ISO를 저장할 공간과 약 500MB의 임시 공간이 필요합니다.

1. 제니아에서 게임을 종료하고 ZIP을 원하는 폴더에 풉니다.
2. `Onechanbara_ISO_Korean_v1.2.8.exe`를 실행합니다.
3. **원본 / 기존 한글판 ISO 선택** 버튼을 누르고 ISO를 선택합니다.
4. 새 ISO를 저장할 위치와 파일 이름을 지정합니다.
5. 완료 후 Xenia에서 생성된 ISO를 직접 불러옵니다.

게임 ISO를 압축 해제할 필요는 없습니다. 입력 ISO는 보존되며 별도의 v1.2.8 ISO가 생성됩니다.

## v1.2.8 변경 사항

팔찌를 다른 아이템으로 잘못 분류하던 공통 판별 오류를 수정했습니다. 게임 내부에서 사용하는 팔찌 식별값을 원본으로 복구하며, 화면에 표시되는 한글 번역은 유지합니다. v1.2.7의 여신상 수정도 포함합니다.

메인 화면의 기존 크레딧 옆에 v1.2.8을 표시합니다.

## 누적 한글화 및 수정

- 장소명·모드명 96곳(원문 31종)
- 캐릭터 꾸미기 설명 240곳 및 뷰 모드 표시 이름 1,183곳
- 게임 대사, 화자 이름, 메뉴와 미션 안내, 엔딩 첫 화면
- 대사 출력 중 잘못된 글자가 보이던 현상 및 열쇠 사용 확인 문구
- 영상 자막 및 홍보 영상 마지막 부제

v1.2.7까지의 한글화와 수정을 모두 포함합니다. 간단한 영어 표기는 일부 유지하며, 배경 간판·장식 글씨와 제작진 실명은 원문을 유지합니다.

## 검수 범위

미션 86개와 공통 아이템·오브젝트 식별값을 대조했습니다. 팔찌 오분류를 게임의 실제 판별 명령으로 재현하고, 수정본의 분류가 원본과 일치하는지 확인했습니다.

제공된 원본 자료와 v1.2.5·v1.2.6·v1.2.7 자료로 구성한 ISO 구조에서 패치 결과 158개 경로와 기존 자료 보존을 검사했습니다. 이전 버전의 입력 허용값도 유지합니다. 이번 통합판으로 제니아에서 엔딩까지 직접 플레이한 검수는 완료하지 않았습니다.
