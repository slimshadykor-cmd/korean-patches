# 오네찬바라 볼텍스 일본판 한글패치 v1.6.0

**한글화 슬림쉐이디**

기존 한글화·영상 자막·로딩 개선과 오네찬바라 전용 실행 구성을 포함한 통합본입니다. 이전 패치를 순서대로 설치할 필요가 없습니다.

## 다운로드

- **[v1.6.0 통합 패치 ZIP 다운로드](https://github.com/slimshadykor-cmd/korean-patches/releases/download/onechanbara-v1.4.0/Onechanbara_Korean_v1.6.0_Integrated.zip)**
- [배포 파일과 변경 내역](https://github.com/slimshadykor-cmd/korean-patches/releases/tag/onechanbara-v1.4.0)

기존 링크를 유지하기 위해 마지막 배포 페이지를 갱신했습니다. 주소의 `onechanbara-v1.4.0`은 기존 태그이며, 현재 첨부 파일과 패치 버전은 **v1.6.0**입니다.

## 적용 방법

1. 제니아를 모두 종료하고 ZIP을 풉니다.
2. `Onechanbara_Korean_v1.6.0.exe`를 실행합니다.
3. **한글패치 적용 — 새 ISO 만들기**에서 일본판 원본 또는 지원되는 기존 한글 ISO를 선택합니다. 입력 파일은 보존합니다.
4. 전용 실행 연결을 사용할 경우 기존 `xenia_canary.exe`를 선택합니다.
5. 완료 후 바탕화면의 **오네찬바라** 바로가기로 실행합니다.

이미 v1.6.0 ISO가 있다면 **전용 실행만 연결** 버튼을 사용하세요. 기존 v1.5.0 ISO는 첫 번째 버튼으로 새 ISO를 만들어야 합니다.

Windows 10/11 64비트, .NET Framework 4.8, Windows PowerShell 5.1이 필요합니다. 원본 및 기존 정식 v1.2.2~v1.5.0 등 지원 해시를 확인하며, 지원하지 않는 파일은 덮어쓰지 않고 중단합니다.

## v1.6.0 변경 사항

- 머리카락 깜박임을 줄인 **Vulkan / FSI / 2x2** 구성과 화면 동기화 설정을 전용 실행에 통합했습니다.
- 실행에 필요한 파일은 `config\Onechanbara` 안에 모았습니다. 원본 제니아 실행파일은 보존하고 그 안에 동일한 전용 사본을 만듭니다.
- 공통 TOML을 그래픽 설정의 원본으로 사용하거나 수정하지 않습니다. 공통 설정을 잠깐 바꿨다가 복원하는 절차도 없습니다.
- 설정·저장 공간·캐시·로그·작업 폴더를 분리합니다. 다른 게임의 설정과 저장 데이터는 변경하지 않습니다.
- 기존 오네찬바라 전용 설정의 비동기 셰이더 값을 이어받습니다. 새 환경의 기본값은 꺼짐입니다.
- 기존 한글화·영상 자막·로딩 개선과 게임 실행 코드는 유지했습니다. 게임 데이터 158개 중 변경된 것은 타이틀의 **v1.6.0** 표기 1개입니다.
- 게임 가속, 60FPS 해제, 콤보 판정 변경 패치는 추가하지 않았습니다. 모든 구간의 끊김 제거를 보장하는 패치는 아닙니다.

## 세이브와 전용 실행

**기존 프로필과 오네찬바라 세이브·DLC·캐시는 처음 연결할 때 전용 폴더로 복사합니다. 이후 저장은 `config\Onechanbara\content`에 쌓이며, 원본 공용 세이브와 자동 동기화하지 않습니다.** 전용 폴더를 삭제하지 마세요. 다시 연결해도 전용 진행 상황과 캐시는 보존합니다.

전용 실행 연결은 사용자 확인 빌드 **Xenia Canary b083312b8 (2026-10-02)**의 실행파일 해시를 검사합니다. 다른 빌드는 연결 체크를 해제하고 한글 ISO만 만들 수 있습니다. 제니아 배포본은 포함하지 않습니다.

기존 오네찬바라 바로가기는 확인 후 같은 이름으로 갱신합니다. 다른 대상을 가리키면 중단합니다. 예전 복구 백업과 다른 게임 폴더는 자동 삭제하지 않습니다.

## 검수 범위

배포 EXE의 ISO 처리·해시 검사, 입력 보존, 설정 분리·실패 복구 등 28개 자동 검사를 통과했습니다. Windows 바로가기와 실행 프로세스는 시험용 대역을 사용했습니다. **새 v1.6.0 연결 구조의 실제 Windows 플레이와 전 챕터·전 난이도 완주를 검증한 것은 아닙니다.** 자세한 내용은 ZIP의 `검수결과.txt`를 확인하세요.

게임 ISO, 사용자 세이브, 개인용 트레이너는 포함하지 않습니다.
