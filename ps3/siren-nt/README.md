# 사이렌 NT 한글 통합패치 v1.5

**[v1.5 릴리스 및 설치기 다운로드](https://github.com/slimshadykor-cmd/korean-patches/releases/tag/siren-nt-v1.5)**

**한글화 슬림쉐이디**

PS3 아시아판 **BCAS20047**용 한글 통합패치입니다. 한글화와 표시 오류 수정, 컷신 보정, RPCS3 전용 옵션을 한 설치기에 담았습니다. 타이틀 화면에 **한글화 슬림쉐이디 v1.5**가 표시됩니다.

## 설치

1. 아래 **Assets**에서 `SIREN_NT_BCAS20047_Korean_v1.5_OneClick.exe`를 다운로드해 실행합니다.
2. 순정 `BCAS20047` ISO를 고르고 **한글 ISO 만들기 · 컷신 필름 입자 정리**를 누릅니다.
3. 결과 ISO를 저장할 폴더를 선택합니다. 처음 실행할 때 필요한 도구를 내려받으려면 인터넷에 연결되어 있어야 합니다.

## 컷신과 작업 시간

- 컷신 **127편**의 필름 입자 노이즈를 줄였습니다. 기본 설정은 원본 명암을 유지하며, **컷신 밝기 추가**를 체크하면 영상이 더 밝아집니다.
- PC에서 영상 127편을 직접 변환·검사한 뒤 새 ISO를 만드는 과정이라, CPU와 저장장치 속도에 따라 오래 걸릴 수 있습니다.
- 작업이 끝나면 설치기가 만든 임시 추출 폴더와 컷신 작업 폴더를 정리합니다.
- **원본 컷신 유지**를 고르면 영상 변환을 건너뜁니다.

RPCS3의 인게임 밝기와 필름 입자 설정은 에뮬레이터의 게임 패치 메뉴에서 선택할 수 있습니다. 60/120 FPS는 실험 옵션입니다.
