# 용과같이 켄잔 한글패치 1.0

**한글화: 슬림쉐이디**

PS3 일본판 원본 게임 폴더에 한 번에 적용하는 통합 한글패치입니다. 이전 패치를 따로 설치할 필요가 없습니다.

## 다운로드

**[한글패치 1.0 다운로드 페이지](https://github.com/slimshadykor-cmd/korean-patches/releases/tag/kenzan-v1.0)**

Assets에 첨부된 한글패치 ZIP을 받으세요. 자동 생성되는 `Source code (zip)` 및 `Source code (tar.gz)`는 설치용 패치가 아닙니다.

## 준비

- 대상 게임: PS3 일본판 **BLJM60064**
- 복호화된 게임 폴더 안에 `PS3_GAME/USRDIR/EBOOT.BIN`이 있어야 합니다.
- Windows 10/11의 기본 Windows PowerShell을 사용합니다. Python 등 별도 설치는 필요 없습니다.
- 게임 드라이브에 **여유 공간 8GB 이상**을 확보하세요.
- 게임과 RPCS3를 완전히 종료하세요.

이 패치는 게임 **폴더**에 적용합니다. ISO 파일에는 직접 적용하지 않습니다.

## 설치

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **`한글패치_실행.bat`**을 실행합니다.
3. **게임 폴더 선택**에서 원본 게임 폴더를 선택합니다.
4. 검사가 끝나면 **한글패치 적용**을 누릅니다.
5. **통합 한글패치 적용 완료**가 표시되면 창을 닫고 RPCS3에서 게임을 실행합니다.

게임의 최상위 폴더, `PS3_GAME`, `USRDIR` 중 하나를 선택할 수 있습니다. 폴더를 창에 끌어 놓거나 **게임 파일로 찾기**에서 `EBOOT.BIN`을 선택해도 됩니다.

ZIP 안에서 바로 실행하지 마세요. `tools`와 `data` 폴더는 실행 파일과 함께 두세요. 적용 중에는 창을 강제로 닫거나 컴퓨터를 끄지 마세요.

## 포함 내용

- 대사·영상 자막·메뉴·설명·이미지 한글화와 누적 수정
- 문장 끝 글자가 선택 뒤에 나타나는 문제 및 대사 표시 보정
- 메뉴·용어설명·인물소개 등의 글자 넘침 수정
- 식당·주점·약국·지도 등 가게 이름 통일
- 편지·대사 오기 및 글자 표시 보정
- 유곽 관련 대사·음식·힌트 검토 내용
- 구매·뒤로 버튼 글꼴 통일
- 저장·불러오기 목록의 제목·진행 설명·난이도와 일본어 저장 안내
- 메인 화면 한글화 표기

## 백업과 복구

설치기는 원본을 자동 백업하고 적용 결과를 검사합니다. 같은 GUI의 **설치 상태 확인**과 **설치 전 복구**를 사용할 수 있습니다.

백업 위치는 `PS3_GAME/_Kenzan_Korean_Backup`입니다. 복구하려면 이 폴더를 보존하세요. 복구는 이번 설치 직전의 게임 파일 상태로 되돌리는 기능이며 세이브와 플레이 진행 상황은 대상이 아닙니다.

설치 중 오류가 발생하면 이번에 교체한 파일을 되돌립니다. 중단된 설치 기록이 표시되면 **설치 전 복구**부터 실행하세요.

다른 리전, 임의 수정본, 누락된 파일은 강제로 덮어쓰지 않습니다. **작업 기록 열기**에서 파일 이름을 확인하세요. 예전 한글판은 파일이 확인되는 경우에만 적용되므로, 불일치가 있으면 일본판 원본 폴더를 사용하세요.

## 세이브와 기존 표시

기존 세이브를 계속 사용할 수 있으며 설치기는 세이브 폴더를 수정하지 않습니다. 옛 저장 슬롯의 영어·일본어 설명은 게임에서 다시 저장하면 갱신됩니다.

RPCS3 자체의 Yes / No 등 영어 표시는 유지합니다. RPCS3 프로그램과 별도로 적용한 그래픽 패치는 수정하지 않습니다.

## 확인 범위

사용자 확인을 거친 누적 수정 파일을 포함했습니다. 기본 한글패치 1,159개 항목과 누적 수정 73개 항목을 통합하여 필수 1,137개, 있으면 함께 처리하는 낱개 파일 24개를 설치합니다.

설치 로직의 적용·백업·복구·오류 처리를 검사했으며, 압축 무결성과 포장된 파일의 일치 여부를 확인했습니다. 지원되는 입력 파일과 생성 결과는 설치 중 검사합니다.

**이번 통합 설치기의 실제 Windows GUI와 원본 게임 폴더 전체 설치·구동은 제작 환경에서 시험하지 못했습니다.** 게임의 모든 장면에 미번역이나 오류가 없다는 보증은 아닙니다. 설치 후 게임 시작, 새 슬롯 저장·불러오기와 주요 수정 화면을 확인하세요. 자세한 내용은 ZIP 안의 `먼저읽기.txt`와 `검증기록.txt`를 참고하세요.
