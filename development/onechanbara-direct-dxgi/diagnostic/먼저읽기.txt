오네찬바라 v1.7 — 출력 비교 검수용
한글화 슬림쉐이디

이 파일은 머리카락 소실 재발과 화면 전달·프레임 문제를 구분하기 위한 비교 실행본입니다.
문제가 해결됐다고 확인한 정식 패치가 아닙니다. 기존 한글 ISO를 그대로 사용합니다.

사용 방법
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. Onechanbara_Diagnostics.exe를 실행합니다.
3. 기존 오네찬바라 설치 기록을 자동으로 찾으면 모드를 선택해 실행합니다.
   자동으로 찾지 못한 경우에만 기존 제니아 폴더의
   config\OnechanbaraDirect\install.json을 선택합니다.
4. 제니아를 종료하면 기록이 자동으로 정리됩니다. 같은 실행기 창에서 다른 모드도 선택할 수 있습니다.
5. [결과 폴더 열기]가 가리키는 마지막 비교결과 ZIP에 그 창에서 실행한 결과가 모두 들어 있습니다.

비교할 때에는 같은 대화 장면을 먼저 확인합니다. 이전에 해결됐던 머리카락 소실이 재발하는지,
이후 같은 위치의 전투에서 동작 표현·프레임·깜빡임이 달라지는지를 구분합니다.
각 모드의 장면과 적 수가 다르면 FPS 숫자만으로 우열을 판단할 수 없습니다.

모드
1. 현재 출력: 직전 paced 출력 구조 + 계측.
2. 대기 경로 비교: 같은 DirectDXGI 출력에서 기존 제니아 UI 표시 정책을 사용.
3. 기존 Vulkan 경로: 직접 DXGI 연결을 사용하지 않는 Vulkan FIFO 출력.
세 모드 모두 Vulkan·FSI·strict·내부배율 2×2를 유지합니다.
모드 2와 3은 비교 대상이며, 성능이나 동작 표현이 좋아진다고 보장하는 선택지가 아닙니다.

첫 준비
기존 캐시를 새 비교 폴더에 복사하고 검증하므로 최초 준비에 시간이 걸릴 수 있습니다.
이후에는 모드별 복사본을 재사용합니다. 첫 실행과 반복 실행 여부는 기록에 남습니다.
사용 중인 원본 캐시는 삭제하거나 바꾸지 않습니다.

실행·종료
게임 실행 때 PowerShell 또는 관리자 권한을 요청하는 구조가 아닙니다.
기존 바로가기·원본 제니아·공용 설정·NVIDIA 프로필을 바꾸는 기능이 없습니다.
게임 저장은 기존 content 위치를 사용합니다. 정상적인 게임 세이브는 그 위치에 기록됩니다.
게임은 제니아 창을 닫거나 [게임 정상 종료 요청]으로 종료할 수 있습니다.
진단 실행기는 기록 정리가 끝난 뒤 닫습니다. 강제 종료 기능은 넣지 않았습니다.

검증 범위
원본 설정 보존, 한글·공백 경로, 실패 후 재시도, 세 모드 설정 차이,
기록 ZIP, 실행파일 구조, 공유 이미지 처리와 GPU query 사용 절차를 검사했습니다.
Windows 전체 빌드 결과와 파일 해시는 validation.json에 기록합니다.
제작 환경에는 실제 Windows GPU가 없어 게임 화면·머리카락·프레임 개선은 검증하지 못했습니다.
