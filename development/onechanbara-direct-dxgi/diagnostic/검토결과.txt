오네찬바라 v1.7 출력 비교용 — 그룹 구현·검수 결과

작업 분담
주 담당: paced 기반 소스 통합, 화면 번호·CPU 대기 계측, Windows 빌드와 패키지 검증.
독립 감사: 동기화·메타데이터 수명·원본 보호·실행 및 종료 경로 교차 검수.
실행기 담당: 일반 권한 네이티브 실행기, 캐시 분리, 실패 기록, 비교 결과 자동 합본.
GPU 측정 담당: 기존 완료 신호를 이용하는 비동기 Vulkan 출력 구간 측정.

이번에 만든 것
공유 이미지 수를 다시 늘리지 않고, 직전 paced-output-1의 단일 공유 이미지 구조를 기준으로 삼았습니다.
이는 정상·완성판이라는 뜻이 아니라 비교 조건을 고정한다는 의미입니다.
출력 경로와 출력 작업의 스레드 정책을 독립적으로 선택할 수 있게 했습니다.
화면에 보이는 버전은 1.7이며 진단 코드의 내부 식별자는 diagnostic-output-1입니다.

확인한 사실과 미확정 사항
이전 대화에서 Vulkan + FSI + strict로 바꾼 뒤 머리카락 문제에 대해 “잘된다”는 사용자 확인이 있습니다.
이전 통합본과 DirectDXGI의 설정 템플릿은 바이트까지 같았습니다.
머리카락 소실 재발 원인은 아직 확정하지 못했습니다. 이미 해결됐던 문제의 재발로 별도 검수합니다.
새 런타임의 변경 대상은 UI 출력 코드입니다. 게임의 GPU 알파·가림 셰이더 직접 수정은 없습니다.
다만 설정이나 소스 범위의 보존만으로 실제 화면 결과가 같다고 보장할 수는 없습니다.

자동으로 기록하는 내용
실행파일·설정·ISO 연결 정보, 실제 실행 인수, 모드와 캐시 사용 상태, 종료 코드.
복사한 후보 패치 파일의 해시와 적용 설정. 실제로 일치·적용된 패치는 xenia.log에서 확인합니다.
DXGI 표시 대기와 allocator 재사용 대기, CPU 완료 대기·명령 기록·제출·Present 호출 시간.
소비한 화면 번호, 성공한 Present API 호출에 연결된 번호의 간격과 중복.
최종 Vulkan 출력 구간의 GPU timestamp. 기존 완료 신호를 확인해 나중에 회수하며 별도 대기를 추가하지 않습니다.

측정값의 정확한 한계
Present API 성공은 모니터에 실제 표시됐다는 증거가 아닙니다.
allocated_latest_id는 게시 직전에 할당한 ID이며 게시 완료보다 한 프레임 앞설 수 있습니다.
consumed_calls는 같은 화면 재소비와 비활성 화면도 포함하는 호출 횟수입니다.
id_gaps는 연속한 성공 API 호출 사이의 번호 간격이며 전체 누락 수가 아닙니다.
첫 성공 API 이전의 간격은 집계하지 않고, 연결 재생성 때 구간을 나눕니다.
CPU 계측은 PaintAndPresentImpl 내부이며 외부 UI tick·paint mutex·게임 렌더링 전체 시간은 아닙니다.
종료 직전 1초 미만의 CPU 집계는 출력되지 않을 수 있습니다.
GPU timestamp는 최종 출력 구간입니다. 세마포어 대기나 동시 작업의 영향을 포함하며 순수 GPU busy 시간이 아닙니다.
전체 게임 렌더링·D3D12 복사·실제 모니터 표시 시간은 이번 계측으로 측정하지 않습니다.
DXGI의 acquire 제한은 UI 16ms / guest 250ms 그대로입니다. native Vulkan의 acquire timeout은 UINT64_MAX입니다.
따라서 두 스레드 정책의 비교에는 원래 timeout 차이도 있으며 이를 순수 스레드 위치 효과라고 단정하지 않습니다.

실행기 검수에서 반영한 사항
원본을 덮어쓰지 않고 별도 세션 폴더에서 실행하며 실패 후 재시도도 새 세션을 사용합니다.
기존 바탕화면 바로가기는 위치를 읽기만 하고 저장하지 않습니다.
NVIDIA DRS 프로필·레지스트리·관리자 권한·게임 실행용 PowerShell 호출을 사용하지 않습니다.
표준출력 기록을 매줄 강제 저장하지 않고 버퍼링해 진단 자체의 추가 부하를 줄였습니다.
같은 창에서 완료한 기록을 한 ZIP으로 묶고 ISO·세이브·캐시는 포함하지 않습니다.
기록에는 사용자 경로가 포함될 수 있으나 자동 외부 전송은 하지 않습니다.

다음 판단 기준
머리카락 정상 표현을 먼저 확인하고, 동일 장면의 동작·혼전 프레임·로딩·깜빡임을 함께 비교합니다.
native 경로와 direct 경로에서 현상이 갈리는지, UI 정책에서 대기와 화면 번호 간격이 어떻게 바뀌는지 확인합니다.
어느 경로도 모든 조건을 통과하기 전에는 정식 개선판으로 교체하지 않습니다.

실제 Windows 게임 플레이는 아직 미검증입니다. 모의 프로토콜 검사를 실제 GPU 검증으로 표시하지 않습니다.
