오네찬바라 볼텍스 ~기혈을 잇는 자들~ 한글패치 v1.2.7

## 변경 사항

- 여신상이 표시되지 않던 문제와 관련된 공통 판별 오류를 수정했습니다.
- 각 챕터에서 사용하는 공통 여신상 판별값을 복구했습니다. 미션 파일 86개를 대조했고, 여신상 이름이 있는 27개 파일에서 같은 식별자를 사용하는 것을 확인했습니다.
- 메인 화면의 크레딧 옆 버전 표시를 v1.2.7로 갱신했습니다.
- v1.2.6까지의 모든 한글화와 수정 내용을 포함한 누적 패치입니다.

## 다운로드 및 적용

아래 **Onechanbara_ISO_Korean_v1.2.7_Release.zip**을 받으세요. ZIP에는 패치 EXE, 사용 안내문, 원본 ISO 해시 안내만 들어 있습니다.

**일본판 원본 ISO와 기존 한글판 ISO 모두 같은 EXE로 적용합니다.** 지원하는 기존 버전은 v1.2.2~v1.2.6이며, 별도 여신상 수정 1(GoddessFix1)을 적용한 ISO도 지원합니다.

ZIP을 풀고 EXE를 실행해 ISO를 선택하면 새로운 v1.2.7 ISO를 만듭니다. 입력 ISO는 보존됩니다. 이전 패치를 순서대로 적용할 필요가 없습니다.

Windows 64비트와 .NET Framework 4.8이 필요합니다. 완료 후 Xenia에서 새 ISO를 직접 불러오세요.
