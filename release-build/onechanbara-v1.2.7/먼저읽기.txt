오네찬바라 볼텍스 ~기혈을 잇는 자들~ 한글패치 v1.2.7
한글화 슬림쉐이디

[이번 수정]
여신상이 표시되지 않던 문제와 관련된 공통 판별 오류를 수정했습니다.
특정 챕터에 한정된 수정이 아니라, 각 챕터에서 사용하는 공통 여신상 판별값을 복구합니다.
미션 파일 86개를 대조했고, 여신상 이름이 있는 27개 파일에서 같은 식별자가 유지됨을 확인했습니다.
메인 화면의 기존 크레딧 옆에 v1.2.7을 표시합니다.
v1.2.6까지의 장소명·모드명·대사·인물 이름·미션 안내·메뉴·영상·엔딩 첫 화면 수정을 모두 포함합니다.

[지원하는 입력]
- 일본판 원본 ISO
- 정식 v1.2.2, v1.2.3, v1.2.4, v1.2.5, v1.2.6 한글판 ISO
- 위 한글판에 별도 여신상 수정 1(GoddessFix1)을 적용한 ISO

새 사용자는 일본판 원본에 이 패치 한 번만 적용하면 됩니다.
기존 사용자는 현재 사용 중인 지원 한글판 ISO에 이 패치를 한 번 적용하면 됩니다.
이전 한글패치나 별도 여신상 수정 도구를 순서대로 다시 적용할 필요가 없습니다.

[준비물]
Windows 64비트 / .NET Framework 4.8
새 ISO를 저장할 여유 공간 및 약 500MB의 임시 여유 공간

[적용 방법]
1. 제니아에서 게임을 종료하고 이 ZIP을 원하는 폴더에 풉니다.
2. Onechanbara_ISO_Korean_v1.2.7.exe를 실행합니다.
3. ISO 선택 버튼으로 일본판 원본 또는 지원하는 기존 한글판 ISO를 선택합니다.
4. 새 ISO의 저장 위치와 이름을 지정합니다.
5. 완료 후 Xenia에서 새로 생성된 ISO를 직접 불러옵니다.

게임 ISO를 압축 해제할 필요는 없습니다.
입력 ISO는 보존되며 별도의 v1.2.7 ISO가 생성됩니다. 기존 파일에는 덮어쓰지 않습니다.
지원하지 않는 파일이라는 메시지가 나오면 실행 파일이나 게임 자료가 다른 빌드일 수 있습니다.
검사값을 우회하지 말고 오류 메시지를 전달해 주세요.

[검수 범위]
여신상 수정은 사용자 실행 확인 후 통합했습니다.
통합판의 게임 실행 파일은 사용자가 확인한 v1.2.6 여신상 수정 실행 파일과 같습니다.
미션별 식별자 보존, 원본 및 지원 한글판의 패치 결과, 기존 자료 보존을 파일 기준으로 검사했습니다.
모든 챕터를 직접 플레이하거나 모든 환경의 튕김 여부를 검증한 것은 아닙니다.

[일본판 원본 ISO 기준 해시]
MD5: a1c8c272378c3ac0bae34c61ff0fc0aa
SHA-1: 13cfb703350719c4e22cfd83100d100e94cb661f
패치 전 원본 ISO의 기준값입니다. 패치 후 ISO의 값은 달라집니다.

간단한 영어 표기와 배경 간판·장식 글씨, 제작진 실명은 원문을 유지합니다.
원본 게임 ISO, Xenia, 세이브 파일, 치트 및 테스트용 도구는 포함하지 않습니다.
