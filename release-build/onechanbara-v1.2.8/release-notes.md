오네찬바라 볼텍스 ~기혈을 잇는 자들~ 한글패치 v1.2.8

## 변경 사항

- 팔찌를 다른 아이템으로 잘못 분류하던 공통 판별 오류를 수정했습니다.
- v1.2.7의 여신상 수정과 이전 한글화·영상 자막을 모두 포함합니다.
- 메인 화면에서 v1.2.8을 확인할 수 있습니다.

## 다운로드 및 적용

아래 `Onechanbara_ISO_Korean_v1.2.8_Release.zip`을 받으세요. 패치 EXE와 사용 안내문, 원본 ISO 해시 안내가 들어 있습니다.

일본판 원본 ISO 또는 정식 v1.2.2~v1.2.7 한글판 ISO에 적용할 수 있습니다. 지원 한글판에 별도 여신상 수정 1(GoddessFix1)을 적용한 ISO도 지원합니다. Windows 64비트와 .NET Framework 4.8이 필요합니다.

ZIP을 푼 뒤 패치 EXE에서 ISO를 선택하면 새 한글판 ISO를 만듭니다. 게임 ISO를 압축 해제할 필요는 없습니다. 입력 ISO는 보존되며 이전 패치를 순서대로 적용할 필요도 없습니다. 완료 후 Xenia에서 새 ISO를 직접 불러오세요.

## 검수 범위

미션 86개와 공통 아이템·오브젝트 식별값을 대조했습니다. 팔찌 오분류를 게임의 실제 판별 명령으로 재현하고 수정 결과를 확인했습니다. 제공된 원본·기존 한글판 자료를 사용한 ISO 구조에서 패치 결과와 자료 보존을 검사했습니다. 이번 통합판으로 제니아에서 엔딩까지 직접 플레이한 검수는 완료하지 않았습니다.
