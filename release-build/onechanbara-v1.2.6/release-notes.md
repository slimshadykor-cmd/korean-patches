오네찬바라 볼텍스 ~기혈을 잇는 자들~ 한글패치 v1.2.6

## 변경 사항

- 모든 구역에서 사용하는 공통 장소명·모드명 96곳(원문 31종)을 추가 한글화했습니다.
- 거리·병원·연구 시설·비행정·서바이벌·연습장 등의 표시를 수정했습니다.
- 메인 화면에 패치 버전을 표시합니다.
- v1.2.5까지의 대사·인물 이름·미션 안내·메뉴·영상·엔딩 첫 화면 수정이 모두 포함된 누적 패치입니다.

## 다운로드 및 적용

아래 `Onechanbara_ISO_Korean_v1.2.6_Release.zip`을 받으세요. ZIP에는 패치 EXE와 사용 안내문, 원본 ISO 해시 안내가 들어 있습니다.

일본판 원본 또는 정식 v1.2.2·v1.2.3·v1.2.4·v1.2.5 ISO에 적용할 수 있습니다. Windows 64비트와 .NET Framework 4.8이 필요합니다.

패치 EXE에서 ISO를 선택하면 새 한글판 ISO를 만듭니다. 게임 ISO를 압축 해제할 필요는 없으며 입력 ISO는 보존됩니다. 완료 후 Xenia에서 새 ISO를 직접 불러오세요.
