[이번 수정]
장소명·모드명 96곳(원문 31종)을 추가 한글화했습니다.
거리, 병원, 연구 시설, 비행정, 서바이벌, 연습장 등의 공통 표시를 수정했습니다.
메인 화면에서 패치 버전을 확인할 수 있습니다.
이전 버전의 대사·인물 이름·미션 안내·메뉴·영상·엔딩 첫 화면 수정도 모두 포함합니다.

[준비물]
- 일본판 원본 ISO 또는 정식 v1.2.2·v1.2.3·v1.2.4·v1.2.5 패치가 적용된 ISO
- Windows 64비트, .NET Framework 4.8
- 새 ISO를 저장할 여유 공간과 약 500MB의 임시 공간

[적용 방법]
1. 이 ZIP을 원하는 폴더에 풉니다.
2. Onechanbara_ISO_Korean_v1.2.6.exe를 실행합니다.
3. ISO 선택 버튼을 누르고 원본 또는 지원되는 기존 패치 ISO를 선택합니다.
4. 새 ISO의 저장 위치와 이름을 지정합니다.
5. 완료되면 Xenia에서 새로 생성된 ISO를 직접 불러옵니다.

게임 ISO 자체를 압축 해제할 필요는 없습니다.
입력 ISO는 보존되며 새 ISO가 생성됩니다. 기존 파일에는 덮어쓰지 않습니다.
정식 v1.2.2·v1.2.3·v1.2.4·v1.2.5 사용자는 해당 ISO에 이번 패치를 한 번 적용하면 됩니다.
게임이나 Xenia를 자동 실행하지 않습니다.
