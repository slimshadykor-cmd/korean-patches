# 닌자가이덴 블랙 한글패치 v1.7 폭풍

**오리지널 Xbox · Japan/Korea (En,Ja)판 · Windows 10/11 64비트 패치 프로그램**

기존 한글화에 선택형 전투 모드 **폭풍**을 추가했습니다. **새 게임에서 블랙/폭풍을 선택**할 수 있습니다. 블랙은 기존 전투와 의상 해금 조건을 사용합니다. 기존 [일반 한글판 v1.6](https://github.com/slimshadykor-cmd/korean-patches/releases/tag/ngb-v1.6)도 그대로 유지합니다.

아래 **Assets → NGB_Korean_Patch_v1.7.zip**을 받으세요. `Source code`는 설치용 패치가 아닙니다.

## 제작 경위

한글화 후 닌자가이덴 블랙을 다른 방식으로도 즐길 수 있도록 시작한 작업입니다. 허리케인 계열 기능에서 아이디어를 얻어 원본에 남아 있는 인터셉트 처리를 활용하고, 모드 선택·추가 효과·비전서·의상 메뉴 연결을 별도로 구현했습니다. 다른 팬 패치의 코드·그림·번역 파일을 빌드 입력으로 사용하지 않았습니다.

## 폭풍의 주요 기능

- **인터셉트:** 1장 초반 첫 죽은 닌자를 조사해 비전서 **교차의 법**을 얻으면 사용할 수 있습니다. 원래 조사 보상은 유지합니다.
- 공격이 닿기 직전에 방어해 인터셉트에 성공한 뒤 바로 근접 공격을 연결하면 **첫 후속 근접 공격에 1.8배 배율**을 적용합니다. 자동 연결 동작은 포함하며 다음 수동 공격은 제외합니다. 보스도 배율 대상이지만 원래 방어·무적 판정은 유지합니다.
- 인터셉트 성공 시 짧은 무적 시간과 **전투 중 카르마 1,000점** 보너스. 유효한 전투 타이머가 필요하고 전투당 카르마 상한은 50,000점입니다. 상시 무적은 아닙니다.
- **그림으로 고르는 류 의상 8개 항목**, 활 조준점과 카메라 기능.
- 블랙/폭풍 선택 화면에서 **Y로 부활 부적 자동 사용 켜기/끄기**. 기본값은 켜짐입니다.
- 저장 시 선택한 모드와 부활 부적 설정을 함께 기록합니다. 폭풍 표시가 없는 기존 저장은 블랙으로 읽으므로 **폭풍은 새 게임과 새 저장 슬롯으로 시작**해 주세요.

클리어 저장·다음 회차와 성공 시 추가 진동은 이번 버전에 포함하지 않았습니다. 의상 선택은 류 전용입니다. 추가 의상 그림 일부는 별도 제작한 미리보기이며 실제 캐릭터에는 원본 모델을 사용합니다.

기존 번역·폰트·정렬·일기·엔딩 크레딧·오류 수정을 포함하며, 시작 화면에 **한글화 슬림쉐이디  v1.7 폭풍**을 표시합니다.

## 설치와 시작

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 지원하는 원본 또는 기존 한글 ISO를 선택하고 **새 한글 XISO 만들기**를 누릅니다.
4. xemu를 완전히 종료한 뒤 새 **`*_Korean_v1.7_Storm.xiso.iso`**로 부팅합니다.
5. **새 게임 → 블랙 또는 폭풍 → 의상 선택** 순서로 시작합니다. 좌우로 선택하고 A 또는 START로 결정합니다.

일반 Xbox ISO와 XISO는 자동 구분하며 **별도 변환 프로그램이나 Python 설치는 필요 없습니다.** 원본 ISO는 보존하고 새 ISO를 만듭니다.

대상 원본, 기존 공용 v1.0·v1.2·v1.3·v1.4·v1.5·v1.6 및 지원되는 기능 시험판에 적용할 수 있습니다. USA/Europe판과 임의 개조본은 지원을 보장하지 않습니다. 패치를 순서대로 설치할 필요는 없습니다.

기존 HDD·세이브 파일은 수정하지 않습니다. 이전 실행 상태 스냅샷 대신 새 ISO로 부팅해 주세요. 자료 갱신으로 첫 로딩이 평소보다 길 수 있습니다.

새 설정의 기본값은 한국어 표시·일본어 음성입니다. HDD에 저장된 설정이 있으면 기존 선택이 우선할 수 있으니 게임 옵션에서 바꿔 주세요. 세이브 삭제나 HDD 교체는 필요하지 않습니다.

## 확인 범위

- 동일 전투 코드를 사용하는 시험판에서 제작자가 **1장 통과**를 확인했습니다.
- 전투·메뉴·비전서 등의 CPU 실행 검사와 기존 한글 자료 보존을 확인했습니다. v1.7은 검수한 시험판의 전투 코드를 유지합니다.
- 원본·이전 판·재적용을 포함한 **합성 ISO/XISO 적용 20건**, ZIP 무결성 및 파일 해시 검사를 통과했습니다.
- 기존 번역 자료 421개 중 **420개는 바이트 단위로 동일**하고, 나머지 한 개는 시작 화면 버전 표시 영역만 바꿨습니다.

**v1.7 최종본의 실제 Windows GUI 실행·xemu 화면·실기 및 전 난이도·전 챕터 완주 검수는 아직 완료하지 못했습니다. 실제 HDD 저장 후 재실행·불러오기 전체 과정도 추가 확인이 필요합니다.** 기존 한글화 검수와 신규 폭풍 기능의 검수 범위는 다릅니다.

게임 ISO·원본 실행 파일·BIOS·HDD·세이브 파일·검수용 상시 무적은 포함하지 않습니다.
