아래 Assets에서 **NGB_Korean_Patch_v1.4.zip**을 받으세요. 자동 생성되는 `Source code` 파일은 설치용 패치가 아닙니다.

### 변경 사항

- 예배당·금고 주변의 일기와 제단 설명 등 추가 번역
- 지하 유적의 조사 문구, 이동 선택지, 일부 미션 대사 추가 번역
- 난이도·미션별 변형을 포함해 **31개 스크립트의 76곳** 보완

### 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 지원하는 원본 ISO 또는 기존 공용 **v1.0/v1.2/v1.3 한글 ISO**를 선택합니다.
4. **새 한글 XISO 만들기** 버튼을 누릅니다.
5. 완료 후 xemu를 완전히 종료하고 새 `*_Korean_v1.4.xiso.iso`로 부팅합니다.
6. 게임 표시 언어를 **한국어**로 선택합니다. 음성은 원하는 언어를 선택하세요.

일반 ISO/XISO는 자동으로 구분하며 **별도 변환 프로그램이나 Python 설치가 필요하지 않습니다.** Windows 10/11 64비트와 새 ISO를 만들 저장 공간이 필요합니다.

이전 패치를 먼저 설치할 필요 없이 이번 패치만 적용하시면 됩니다. 원본 ISO는 보존하며 **기존 게임 내 세이브도 그대로 사용합니다.** 별도의 세이브 패치는 필요 없습니다. 이전 xemu 스냅샷 대신 새 ISO로 부팅한 뒤 게임 내 세이브를 불러오세요.
