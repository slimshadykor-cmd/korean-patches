### v1.3 변경 사항

- ‘주 메뉴’를 ‘메인메뉴’로 바꾸고 가운데 정렬했습니다.
- 일부 미션·게임 저장·아케이드 제목의 정렬을 보정했습니다.
- 지도·메뉴의 **확대·축소, 뒤로, 선택** 안내를 패드 아이콘에 맞춰 배치했습니다.
- 이미 수정된 저장 목록·챕터 화면 등의 배치는 유지했습니다.

기존 v1.2는 그대로 보관하며, 이번 수정본은 v1.3으로 새로 배포합니다. 지원하는 원본 또는 기존 v1.0/v1.2 한글 ISO에 바로 적용할 수 있습니다.

일반 ISO와 XISO는 자동으로 구분합니다. **버튼 하나로 필요한 변환과 한글패치를 함께 처리**하며, 별도 변환 프로그램이나 Python 설치가 필요하지 않습니다. 원본은 보존하고 새 `*_Korean_v1.3.xiso.iso` 파일을 만듭니다.

### 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. **Japan/Korea (En,Ja)판 ISO 또는 XISO**를 선택합니다.
4. 큰 **새 한글 XISO 만들기** 버튼을 누릅니다.
5. 완료 후 xemu를 완전히 종료하고 **새로 만들어진 ISO**로 부팅합니다.
6. 게임 표시 언어를 **한국어**로 선택합니다. 음성은 원하는 언어를 선택하세요.

Windows 10/11 64비트와 새 ISO를 만들 저장 공간이 필요합니다. 지원하는 원본 ISO와 기존 v1.0/v1.2 한글 ISO에 사용할 수 있으며, 이전 패치를 먼저 설치할 필요는 없습니다.

**기존 게임 내 세이브는 그대로 사용합니다.** 이전 xemu 스냅샷 대신 새 ISO로 부팅한 후 게임 내 세이브를 불러오세요.
