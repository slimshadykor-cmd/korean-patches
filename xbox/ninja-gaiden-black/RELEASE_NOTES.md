# 닌자가이덴 블랙 한글패치 v1.6

**오리지널 Xbox · Japan/Korea (En,Ja)판**

이번 버전은 새 설정의 기본 언어를 **한국어 표시·일본어 음성**으로 바꾼 편의 업데이트입니다. 기존 번역·폰트·정렬·일기와 안내 문구·엔딩 크레딧·오류 수정, ISO/XISO 자동 처리를 모두 포함합니다.

아래 Assets에서 **NGB_Korean_Patch_v1.6.zip**을 받으세요. `Source code` 파일은 설치용 패치가 아닙니다.

## 이번 변경

- 게임 설정 초기화 시 한국어 표시·일본어 음성을 기본값으로 설정
- 시작 화면의 한글화 크레딧 옆 버전 표시를 v1.6으로 갱신
- 기존 번역·폰트·배치와 누적 오류 수정 보존

**이미 HDD에 저장된 게임 설정이 있다면 기존 언어·음성 선택이 적용될 수 있습니다.** 이 경우 옵션에서 표시 언어 **한국어**, 음성 **일본어**를 선택해 주세요. 원하는 음성으로 바꿀 수도 있으며, 세이브 삭제나 HDD 교체는 필요하지 않습니다.

## 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 지원하는 원본 또는 기존 한글 ISO를 선택합니다.
4. **새 한글 XISO 만들기**를 누릅니다.
5. xemu를 완전히 종료하고 새 **`*_Korean_v1.6.xiso.iso`**로 부팅합니다.

일반 Xbox ISO와 XISO는 자동 구분하며 **별도 변환 프로그램이나 Python 설치가 필요 없습니다.** Windows 10/11 64비트와 새 ISO를 만들 저장 공간이 필요합니다.

지원 입력은 대상 원본과 기존 공용 v1.0·v1.2·v1.3·v1.4·v1.5, 한국어 기본값 Test1 및 한국어·일본어 음성 Test2입니다. 이전 패치를 순서대로 설치할 필요 없이 이번 패치만 적용하세요. USA/Europe판이나 임의 개조본까지 지원하는 것은 아닙니다.

**원본 ISO와 기존 게임 내 세이브는 보존합니다.** 별도 세이브 패치가 필요 없습니다. 이전 xemu 스냅샷 대신 새 ISO로 부팅한 뒤 게임 내 세이브를 불러와 주세요. 자료 갱신으로 첫 로딩은 평소보다 길 수 있습니다.

## 확인 범위

- 기존 게임 자료 421개 중 420개가 바이트 단위로 동일하며, 나머지 한 개는 기존 버전 숫자 영역만 변경했습니다.
- 배포된 메시지·자막의 검사 가능한 경로에서 추가 미번역·깨진 문자 후보를 찾지 못했습니다. 문자열 참조·로더 크기·이미지 자료 구조·폰트 문자표도 검사했습니다.
- 기본값 CPU 실행 72가지, 저장된 언어·음성 복원 4가지 검사를 통과했습니다.
- 실제 실행 파일·로더·demo.afs를 사용한 합성 ISO/XISO 적용 검사 10가지와 ZIP 무결성 검사를 통과했습니다.

**v1.6 최종본의 실제 Windows GUI 실행·xemu 부팅과 전 난이도·전 챕터 완주 검수는 아직 완료하지 못했습니다.** 모든 화면의 겹침·잘림이나 모든 실행 분기를 확인했다는 뜻은 아닙니다. 자세한 범위는 ZIP의 검사 기록을 참고하세요.

공용판에는 **치트·세이브 파일·세이브 도구가 없습니다.** 게임 ISO·원본 실행 파일·BIOS·HDD·에뮬레이터도 포함하지 않습니다. 영어 곡명 등 의도적으로 남긴 표기는 유지했습니다.
