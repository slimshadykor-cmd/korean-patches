### 설치

ZIP 전체 압축 해제 → **NGB_Korean_Patch.exe** 실행 → 원본 ISO 선택 → **새 한글 ISO 만들기**.

별도 Python 설치 없이 사용할 수 있습니다. 완성된 새 ISO로 xemu를 부팅하고 표시 언어를 한국어로 선택하세요.

### 원본 확인용 해시

대상 원본 내부 **default.xbe** (4,571,136바이트)의 SHA-256:
`667b6c04e0952ebf39848ea59ab8f8457ae3136c3d115f268557d861eeade6ce`

**이 값은 ISO 전체 해시가 아닙니다.** 추출된 게임 파일로 작업했으므로 원본 ISO 전체 해시는 아직 미확인입니다. 배포 ZIP 해시는 첨부된 SHA256SUMS.txt를 확인하세요.
