# 닌자가이덴 블랙 패치 작업·회귀검사 기준

이 프로젝트를 수정하거나 배포할 때 아래의 실제 발생 문제와 미확인 범위를 검사 계획에 반영한다. 기존에 정상인 번역·그림·기능은 변경 필요성이 입증되지 않으면 보존한다. 사용자의 최신 지시를 우선한다.

## 변경 영향 분석
- 문구 추가·교체 시 문자열 길이, 종료 문자, 언어 구분자, 제어 코드, 포인터, 파일 헤더 길이, AFS 항목 크기, 로더 정보, 캐시 세대를 확인한다.
- 해당 데이터의 크기·주소·문자열 내용에 의존하는 실행파일 및 이벤트 조건을 역으로 찾는다. 번역 파일 자체의 무결성만으로 기능 정상 판정을 내리지 않는다.
- 사례: v1.8에서 1장 STY에 번역을 추가한 뒤 폭풍 비전서 지급 식별표의 옛 길이가 남아 최초 지급이 누락되었다. 현재 최종 STY에서 지급 식별값을 산출·대조하고 난이도별 분기 및 다른 장소와의 충돌을 검사한다.
- 수정한 범위와 기존 정상 부분을 바이트·해시로 대조한다. 이미 확인한 자료는 재사용하되, 검사 대상 파일의 해시가 바뀌면 기존 결과를 그대로 적용하지 않는다.

## 모드·진행 조건
- 블랙과 폭풍 양쪽을 검사한다. 공통 번역 처리와 폭풍 전용 기능을 따로 확인한다.
- 전 챕터와 엔딩을 목록에 포함하고 난이도·미션·재방문별 복사본 및 다른 이벤트 분기를 확인한다. 파일명만으로 실제 난이도 대응이나 도달 가능성을 단정하지 않는다.
- 새 게임, 정상 종료 후 재실행, 게임 내 저장·불러오기, 이전 버전 세이브, 이미 이벤트를 마친 세이브를 구분한다.
- 폭풍 첫 죽은 닌자: 기존 아이템과 교차의 법 비전서의 실제 소지, 미소지·기소지, 이벤트 표시 플래그, 가득 찬 인벤토리, 다른 장소, 난이도별 분기를 확인한다. 블랙에는 폭풍 비전서를 지급하지 않는다.
- 인터셉트 해금, 첫 후속 공격 배율, 무적 시간·카르마, 의상, 활·카메라, 부활 부적 옵션, 모드 저장·복원도 변경 영향이 있으면 재검사한다.
- 지급 분기 진입, 아이템 지급 함수의 모의 실행, 실제 인벤토리 증가 및 게임 내 획득은 서로 다른 검증 수준으로 기록한다.

## 번역·화면
- 예배당 책·금고 힌트·금고 내부 책·일기·3장 2등 기관사 보고서 등 과거 누락 사례와 같은 저장 형식을 모두 검색한다.
- 다국어 블록, 두 언어 블록, 끝 구분자, 구분자 없는 문구, 직접 그리는 메시지, 실행파일 문자열, 영상 자막, 그림 속 글자를 구분한다.
- 글꼴 누락·네모·깨진 한자 무늬, 지역 이동 글자, 카르마 숫자, 게임오버 잘림, 메뉴·난이도·의상 정렬, 아이템 탭 돌출, 챕터 밑줄, 진행/불러오는 중 위치와 본문 겹침을 변경 영향에 따라 확인한다.
- 흑룡검 용어와 조사, 한국어 표시 언어, 요청대로 유지하는 영어 곡명·메뉴, 시작 화면 크레딧·버전, 엔딩 크레딧을 확인한다.
- 사용자가 허용하지 않은 배경·무늬·그림 재디자인은 하지 않는다.

## 실행·배포
- 무비시어터 자연 종료와 수동 종료를 각각 확인한다. 실제 엔딩과 무비시어터의 마지막 영상은 같은 경로라고 가정하지 않는다.
- 14장 정지 보고 등은 원본·패치·환경을 비교하고 원인 미확정 상태를 유지한다. 실제 Xbox, xemu, 다른 호환 환경의 검증을 혼동하지 않는다.
- 표시 언어·음성 기본값은 새 HDD/기존 설정, 새 게임/로드, 재실행에서 다를 수 있음을 확인한다.
- 원본 일반 ISO, XISO, 지원 이전 패치, 재적용의 관련 경로와 최종 파일 재읽기·해시·ZIP 무결성을 검사한다.
- 공용판에 개인 무적 치트·세이브·HDD 이미지가 섞이지 않도록 확인한다. 선택형 폭풍 기능과 개인 검수 치트는 구분한다.
- 배포 파일·설명·버전·해시를 일치시키고 실제 공개 다운로드를 검증한다. 사용자에게는 해당 게임의 정확한 릴리스 링크를 제공한다.
- 새 문제가 기존 세이브에서 자동 복구되는지 별도로 확인한다. 지원하지 않는 복구를 가능하다고 안내하지 않는다.

## 결과 보고 원칙
- 검사 항목마다 통과·실패·미확인·해당 없음과 근거를 남긴다.
- 정적 검사, 네이티브 CPU 검사, 모의 함수 경계, 화면 렌더링, xemu 실제 플레이, 실기 확인을 명확히 구분한다.
- 실행하지 않은 조합을 실행했다고 하지 않는다. 모든 챕터의 데이터 조사와 모든 챕터의 실제 완주는 다르다.
- 새 실패나 변경 영향이 없다면 비용 절약을 위해 같은 검사를 불필요하게 반복하지 않는다. 필요한 검수를 생략하지 않는다.
- 현재 보너스 게임 ROM 한글화, 모든 그림의 실제 표시 경로, 전 난이도·전 챕터 실제 완주는 완료로 간주하지 않는다.


## 설정 읽기·교차 저장 재발 방지 (2026-10-25)
- 같은 슬롯의 블랙→블랙, 블랙→폭풍, 폭풍→블랙, 폭풍→폭풍과 양쪽 3회 연속 교차 덮어쓰기를 구분한다. 저장 직후 로드와 리셋·완전 종료 후 로드도 구분한다.
- 설정(system.dat)과 게임 진행 저장은 별도 경로다. 시작 경고를 저장 파일 손상으로 단정하지 않고 반환 지점과 실제 실패 원인을 추적한다. 조기 반환으로 진단값이 갱신되지 않는 경우도 검사한다.
- 작업 메모리 확보 실패·정렬·크기, 정상 파일·잘림·서명 손상을 구분한다. 오류를 숨기거나 검증을 우회하지 않는다. 모의 OS/서명과 네이티브 내부 처리, 사용자 xemu 확인의 범위를 각각 기록한다.
- 사용자가 업데이트를 지시하면 해당 게임 릴리스 파일 교체, 날짜·수정 사항·확인 범위·해시 설명 갱신을 함께 수행한다. 별도로 다시 지시하도록 요구하지 않는다. 게시판 글 작성과 실제 게시를 구분한다.
