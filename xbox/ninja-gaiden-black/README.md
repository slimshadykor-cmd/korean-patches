## v1.8 추가 수정 — 폭풍 비전서 미지급 안내

**수정 전 v1.8에서 폭풍으로 새 게임을 시작하면, 첫 죽은 닌자의 기존 아이템은 받아도 비전서 ‘교차의 법’이 지급되지 않는 문제가 있었습니다.** 비전서가 없으면 폭풍의 인터셉트를 사용할 수 없습니다.

처음 폭풍 기능을 넣었을 때는 정상 작동했으나, v1.8에서 번역 누락을 보완하며 1장 스크립트 길이가 바뀌었습니다. 이때 비전서 지급 위치를 식별하는 조건에 이전 길이가 남았습니다.

이번 수정본은 난이도별 1장 스크립트 5개의 조건을 갱신했습니다. **폭풍에서는 초반 그 죽은 닌자에게서 기존 아이템과 ‘교차의 법’ 비전서를 함께 받도록 복구했습니다.** 블랙은 기존 아이템 지급을 유지하며 폭풍 전용 비전서를 추가하지 않습니다.

**버전과 다운로드 링크는 v1.8 그대로입니다.** 이전 v1.8 ZIP을 받으셨다면 아래 순서로 재적용해 주세요.

1. ZIP을 다시 다운로드하여 새 폴더에 전부 압축 해제합니다.
2. `NGB_Korean_Patch.exe`로 지원 원본 또는 기존 공용 v1.8 ISO에 패치를 적용합니다.
3. xemu를 완전히 종료한 뒤 새로 만든 ISO로 부팅합니다. 이전 실행 상태를 복원하는 스냅샷은 사용하지 않습니다.

**기존 게임 내 세이브는 유지됩니다. 다만 이미 해당 장소를 지나쳐 비전서를 놓친 세이브에 자동으로 비전서를 넣어 주는 수정은 아닙니다.** 지급 확인은 새 게임 → 폭풍에서 첫 죽은 닌자를 조사하는 방식으로 해 주세요. 이미 비전서를 받은 세이브에서는 최초 지급 여부를 다시 확인할 수 없습니다.

공통 문구 처리와 모드 정보 저장·복원, 비전서 지급 조건을 코드 실행으로 검사했습니다. 수정 전 미지급은 사용자 플레이에서도 확인했습니다. **수정 후 실제 xemu 플레이 확인은 아직이며, 전 난이도·전 챕터 완주 검수가 끝났다는 의미는 아닙니다.** 흑룡검 명칭 통일과 기존 한글화도 포함되어 있습니다.

## 폭풍의 주요 기능

- **인터셉트:** 1장 초반 첫 죽은 닌자를 조사해 비전서 **교차의 법**을 얻으면 사용할 수 있습니다. 원래 조사 보상은 유지합니다.
- 공격이 닿기 직전에 방어해 인터셉트에 성공한 뒤 바로 근접 공격을 연결하면 **첫 후속 근접 공격에 1.8배 배율**을 적용합니다. 자동 연결 동작은 포함하며 다음 수동 공격은 제외합니다. 보스도 배율 대상이지만 원래 방어·무적 판정은 유지합니다.
- 인터셉트 성공 시 짧은 무적 시간과 **전투 중 카르마 1,000점** 보너스. 유효한 전투 타이머가 필요하고 전투당 카르마 상한은 50,000점입니다. 상시 무적은 아닙니다.
- **그림으로 고르는 류 의상 8개 항목**, 활 조준점과 카메라 기능.
- 블랙/폭풍 선택 화면에서 **Y로 부활 부적 자동 사용 켜기/끄기**. 기본값은 켜짐입니다.
- 저장 시 선택한 모드와 부활 부적 설정을 함께 기록합니다. 폭풍 표시가 없는 기존 저장은 블랙으로 읽으므로 **폭풍은 새 게임과 새 저장 슬롯으로 시작**해 주세요.

클리어 저장·다음 회차와 성공 시 추가 진동은 이번 버전에 포함하지 않았습니다. 의상 선택은 류 전용입니다. 추가 의상 그림 일부는 별도 제작한 미리보기이며 실제 캐릭터에는 원본 모델을 사용합니다.

기존 번역·폰트·정렬·일기·엔딩 크레딧·오류 수정을 포함하며, 시작 화면에 **한글화 슬림쉐이디  v1.8 폭풍**을 표시합니다.

## 설치와 시작

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 지원하는 원본 또는 기존 한글 ISO를 선택하고 **새 한글 XISO 만들기**를 누릅니다.
4. xemu를 완전히 종료한 뒤 새 **`*_Korean_v1.8.xiso.iso`**로 부팅합니다.
5. **새 게임 → 블랙 또는 폭풍 → 의상 선택** 순서로 시작합니다. 좌우로 선택하고 A 또는 START로 결정합니다.

일반 Xbox ISO와 XISO는 자동 구분하며 **별도 변환 프로그램이나 Python 설치는 필요 없습니다.** 원본 ISO는 보존하고 새 ISO를 만듭니다.

대상 원본, 기존 공용 v1.0·v1.2·v1.3·v1.4·v1.5·v1.6·v1.7 및 지원되는 기능 시험판에 적용할 수 있습니다. USA/Europe판과 임의 개조본은 지원을 보장하지 않습니다. 패치를 순서대로 설치할 필요는 없습니다.

기존 HDD·세이브 파일은 수정하지 않습니다. 이전 실행 상태 스냅샷 대신 새 ISO로 부팅해 주세요. 자료 갱신으로 첫 로딩이 평소보다 길 수 있습니다.

새 설정의 기본값은 한국어 표시·일본어 음성입니다. HDD에 저장된 설정이 있으면 기존 선택이 우선할 수 있으니 게임 옵션에서 바꿔 주세요. 세이브 삭제나 HDD 교체는 필요하지 않습니다.

## 확인 범위

전체 원본 자료 목록을 기준으로 326개 STY·140개 RTM·4개 MES와 실행 파일의 문구를 조사했습니다. 인식된 표시 문구 블록 4,013개와 이벤트 자막의 한국어 슬롯에서 남은 일본어 후보가 검출되지 않았습니다. 실제 CPU의 문구 읽기 경로 496건, 원본 XISO·일반 ISO·v1.7 업데이트·재적용 검사, ZIP 무결성과 파일별 해시 검사를 통과했습니다.

4~6장에 사용되는 지역의 난이도·재방문·미션 자료 89개를 별도로 대조했습니다. 한국어·영어 출력 경로 3,042건을 실행했고, 조사 문구의 버튼·색상 제어 코드와 원본 진행 조건이 보존됨을 확인했습니다.

**이것은 전 난이도·전 챕터·엔딩의 실제 플레이 완주 검수와 다릅니다. v1.8의 실제 Windows GUI 실행·xemu 화면·실기와 모든 진행 분기는 미검증이며, 추가 게임 ROM 내부 문구와 모든 이미지의 표시 경로도 검증하지 못했습니다. ‘100% 검수 완료’ 또는 ‘모든 미번역 0건’으로 안내하지 않습니다.**

게임 ISO·원본 실행 파일·BIOS·HDD·세이브·검수용 상시 무적은 포함하지 않습니다.
