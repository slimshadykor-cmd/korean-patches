## 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제하고 **NGB_Korean_Patch.exe**를 실행합니다.
2. 지원하는 원본·기존 한글판 ISO/XISO 또는 게임 폴더의 **default.xbe**를 선택합니다.
3. **새 파일 저장 위치** 옆 **저장 위치** 버튼으로 저장할 곳을 고릅니다.
4. **한글패치 적용 — 새 파일 만들기**를 누릅니다.
5. ISO 입력은 만들어진 새 XISO를 사용합니다. default.xbe 입력은 생성된 **적용방법.txt**를 따라 교체 파일을 게임 폴더에 적용합니다. 출력 폴더 자체는 게임 전체가 아닙니다.

Japan/Korea (En,Ja)판과 기존 패처가 지원하던 한글판을 지원합니다. default.xbe 입력에는 같은 폴더의 게임 자료가 필요합니다. 원본·세이브·HDD를 덮어쓰거나 변환하지 않습니다. 별도 Python 설치나 인터넷 연결은 필요 없습니다.

## 경고문 언어와 확인 범위

시작 시 경고문은 게임 내 표시 언어와 별도로 **본체 지역 값**을 읽습니다. 현재 게임 코드에서 지역 값 2는 한글, 다른 값은 영어 경고문을 선택합니다. 같은 패치라도 xemu와 실기에서 제공하는 지역 값에 따라 달라질 수 있으며, 이번에는 이 동작을 유지했습니다. 두 제보 환경의 실제 지역 값은 직접 확인하지 않았습니다.

- 직전 공용 v2.1에 대한 **사용자님의 xemu 정상 실행 확인**을 반영했습니다. 영어 경고문도 이전부터 동일했다는 확인입니다.
- 이번 위치 수정본은 제목 영역 밖의 픽셀과 게임 동작 코드·번역 자료 보존, 원본/기존 한글판 변환, 29개 실제 AFS, 폴더/ISO/XISO 출력 및 재적용 검사를 통과했습니다.
- 과거 PC Xenia Edge + XeFu3 실행 기록과 x86 코드 검사, 저장 위치 UI 12개 동작 검사는 해당 과거 빌드의 기록으로 구분해 유지합니다. 이번에 실행 명령어와 GUI는 바꾸지 않았습니다.
- 이번 위치 수정본을 모든 기기에서 직접 실행하거나 전 챕터 완주한 것은 아닙니다. 실제 실행 확인과 파일·코드 검사를 구분합니다.

상세 기록은 ZIP의 `audit/verification.json`과 `README_KO.txt`에 있습니다.

## 확인 범위

이번 부활 부적 수정본은 제작자가 정상 작동을 확인했습니다. 정식판은 확인한 수정본과 동일한 게임 코드를 사용하며, 배포용 표시와 안내문을 정리했습니다. 메뉴·부활 처리, 블랙/폭풍 교차 저장을 포함한 네이티브 CPU 검사와 지원 실행파일 11종·합성 ISO/XISO 10가지 패치 적용 검사를 통과했습니다. 실제 플레이 확인 범위를 모든 난이도·챕터·환경으로 확대하지 않습니다.

이전 공용판의 저장 화면 메모리 수정은 제작자가 xemu에서 확인했습니다. 이번에 통합한 선택 화면 메모리 수정은 **제보자가 hakuX에서 새 게임 및 1장까지 정상 진행했다고 확인**했습니다. 당시 선택 화면 수정은 hakuX 제보 범위로 기록했으며, 이를 모든 환경·전 챕터의 확인으로 확대하지 않습니다.

코드 검사에는 블랙/폭풍/교차 저장 72개 시나리오·저장/읽기 168쌍, 그림 자원 재사용·해제·실패 처리, 기존 그림·배치 보존 검사가 포함됩니다. 이번 선택 화면 수정에서는 입력 16가지, 그림·배치 대조 52가지, 자원 해제·재시도·반복 전환, 지원 실행파일 10종 변환과 실제 패처의 합성 ISO/XISO 8가지 적용·재적용을 검사했습니다. 공용 통합 과정에서는 동일 실행파일·패치 처리의 기존 검사 결과를 재사용하고, 2,724개 파일 해시와 ZIP 무결성을 확인했습니다.

**전 난이도·전 챕터·모든 환경의 실제 완주 검수를 완료했다는 뜻은 아닙니다.** 실기·Windows GUI 전체 실행과 보너스 게임 내부 한글화도 확인 완료로 안내하지 않습니다. 에뮬레이터 버전·설정·환경에 따라 동작이 달라질 수 있습니다. 일반 구동 문제는 [xemu 공식 문서](https://xemu.app/docs/)와 기존 사례를 먼저 확인해 주세요.
