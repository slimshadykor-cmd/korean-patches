### 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 지원하는 원본 ISO 또는 기존 공용 v1.0·v1.2·v1.3·v1.4 한글 ISO를 선택합니다.
4. **새 한글 XISO 만들기**를 누릅니다.
5. 완료 후 xemu를 완전히 종료하고, 새 **`*_Korean_v1.5.xiso.iso`**로 부팅합니다.
6. 게임 표시 언어를 **한국어**로 선택합니다. 음성은 원하는 언어를 사용하세요.

일반 Xbox ISO와 XISO는 자동으로 구분합니다. **별도 변환 프로그램이나 Python 설치가 필요하지 않습니다.** Windows 10/11 64비트와 새 ISO를 만들 저장 공간이 필요합니다.

이전 패치를 순서대로 설치할 필요 없이 v1.5만 적용하시면 됩니다. 입력 ISO는 보존하며 **기존 게임 내 세이브도 그대로 사용합니다. 세이브 패치는 다시 하지 않아도 됩니다.** 이전 xemu 스냅샷 대신 새 ISO로 부팅하고 게임 내 세이브를 불러와 주세요. 자료 갱신으로 첫 로딩은 평소보다 길 수 있습니다.

### 확인 범위

11장 보통 난이도의 일기·이동 선택지와 이후 검수판의 한글 표시를 사용자 플레이로 확인했습니다. 배포본은 파일 구조·메모리 처리·일반 ISO/XISO 적용·압축파일 무결성을 검사했습니다. 공용판의 체력 처리는 원래 게임과 같으며, 무비 시어터 마지막 항목도 본래 영상입니다.

**전 난이도·전 구간을 실제 플레이로 완주 검수한 것은 아닙니다.** v1.5 공용 패키지의 실제 Windows GUI 실행과 xemu 전체 구동은 제작 환경에서 확인하지 못했습니다. 무비 시어터의 자연 종료·중간 종료 각각에 대한 최종 복귀 확인도 별도로 완료된 상태는 아닙니다.

공용판에는 **치트·세이브 파일·세이브 도구가 없습니다.** 게임 ISO·BIOS·HDD·에뮬레이터도 포함하지 않습니다. 영어 곡명 등 의도적으로 남긴 표기는 유지합니다.

에뮬레이터 버전·설정·PC 환경에 따라 문제가 발생할 수 있습니다. 일반 구동 문제는 [xemu 공식 문서](https://xemu.app/docs/)와 기존 사례를 먼저 확인해 주세요. 번역 오류나 글자 깨짐·잘림은 **발생 장소와 상황, 스크린샷, 패치/xemu 버전**을 함께 알려주시면 확인에 도움이 됩니다.
