# 닌자가이덴 블랙 한글패치 v1.2

**[v1.2 다운로드 페이지](https://github.com/slimshadykor-cmd/korean-patches/releases/tag/ngb-v1.2)**

**오리지널 Xbox · Japan/Korea (En,Ja)판 · 한글화: 슬림쉐이디**

**일반 ISO인지 XISO인지 직접 구분할 필요 없이, 버튼 하나로 한글 XISO를 만드는 v1.2입니다.**

아래 **Assets의 `NGB_Korean_Patch_v1.2.zip`**을 받으세요. 자동 생성되는 Source code 파일은 설치용 패치가 아닙니다.

### v1.2 변경 사항

- 일반 Xbox ISO는 자동으로 XISO로 변환하면서 한글패치를 적용합니다.
- 이미 XISO인 파일도 같은 버튼으로 패치합니다.
- 별도의 변환 프로그램이나 `extract-xiso -r` 작업, Python 설치가 필요하지 않습니다.
- 원본 파일을 보존하고 새 `*_Korean_v1.2.xiso.iso` 파일을 만듭니다.

기존 대사·아이템·메뉴·지역명·지도·상점 등의 한글화와 화면 보정은 그대로 포함했습니다. **v1.0으로 정상 플레이 중이라면 반드시 다시 패치할 필요는 없습니다.**

### 적용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. **Japan/Korea (En,Ja)판 ISO 또는 XISO**를 선택합니다.
4. 큰 **새 한글 XISO 만들기** 버튼을 누릅니다.
5. 완료 후 xemu를 완전히 종료하고 **새로 만들어진 ISO**로 부팅합니다.
6. 게임 표시 언어를 **한국어**로 선택합니다. 음성은 원하는 언어를 선택하세요.

Windows 10/11 64비트와 새 ISO를 만들 저장 공간이 필요합니다. 지원하는 원본 ISO와 기존 v1.0 한글 ISO에 사용할 수 있으며, 이전 패치를 먼저 설치할 필요는 없습니다.

**기존 게임 내 세이브는 그대로 사용합니다.** 이전 xemu 스냅샷 대신 새 ISO로 부팅한 후 게임 내 세이브를 불러오세요.

### 확인 범위와 문제 제보

기존 한글화 플레이 검수는 **2026년 10월 11일 당시 최신 xemu**를 기준으로 진행했습니다. v1.2 자동 변환은 합성 ISO를 이용해 일반 ISO/XISO 및 원본/기존 패치 입력, 원본 보존, 결과 재읽기, 잘못된 입력 거부를 검사했으며 배포 ZIP 무결성도 확인했습니다. **v1.2 설치기의 실제 Windows GUI 실행과 실제 게임 ISO 변환 후 xemu 구동은 제작 환경에서 확인하지 못했습니다.**

에뮬레이터 버전·설정·PC 환경·게임 데이터·저장 상태에 따라 문제가 발생할 수 있습니다. 이번 업데이트가 모든 검은 화면·멈춤 문제를 해결하는 것은 아닙니다. 일반 구동 문제는 [xemu 공식 문서](https://xemu.app/docs/)와 기존 사례를 먼저 확인해 주세요.

공용판에는 **무적·검수용 치트, 세이브 파일·세이브 도구가 없습니다.** 게임 ISO·BIOS·에뮬레이터도 포함하지 않습니다.

번역 오류나 글자 깨짐·잘림이 보이면 발생 장면, 스크린샷, 패치/xemu 버전을 함께 알려주세요. 사용 후기와 응원도 감사히 받겠습니다!
