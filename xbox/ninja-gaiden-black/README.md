# 닌자가이덴 블랙 한글패치 v1.0

**오리지널 Xbox판 · 한글화: 슬림쉐이디**

스토리 대사, 아이템 설명, 메뉴·지역명을 한국어로 옮기고 지도와 여러 화면의 글꼴·배치를 다듬었습니다. 영어 곡명과 일부 원작 디자인 표기는 유지합니다.

## 다운로드

**[한글패치 v1.0 ZIP 받기](https://github.com/slimshadykor-cmd/korean-patches/releases/download/ngb-v1.0/NGB_Korean_Patch_v1.0.zip)**

검수용 무적·체력 보호 치트는 포함하지 않습니다. 게임 ISO·BIOS·에뮬레이터·세이브 파일은 제공하지 않습니다.

## 설치

대상은 **Ninja Gaiden Black — Japan/Korea (En,Ja) 원본 Xbox ISO**입니다. Windows 10/11 64비트와 새 ISO를 만들 여유 공간이 필요합니다. **Python 별도 설치는 필요 없습니다.**

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. **NGB_Korean_Patch.exe**를 실행합니다.
3. 원본 ISO를 선택하고 큰 **새 한글 ISO 만들기** 버튼을 누릅니다.
4. 완료 후 xemu를 완전히 종료하고 새로 생성된 **`*_Korean_v1.0.iso`**를 실행합니다.
5. 게임의 표시 언어를 **한국어**로 선택합니다. 음성은 원하는 언어를 선택하세요.

원본 ISO와 게임 내 세이브는 보존됩니다. 세이브 패치를 다시 할 필요는 없습니다. 예전 xemu 스냅샷을 이어 쓰지 말고 새 ISO로 부팅한 뒤 게임 내 세이브를 불러오세요. 다른 지역판이나 임의 수정본은 적용이 거부될 수 있습니다.

## 원본 확인용 해시

대상: **Ninja Gaiden Black — Japan/Korea (En,Ja)**

현재 확인된 값은 원본 게임 내부의 **`default.xbe` 파일** 기준입니다.

| 항목 | 값 |
| --- | --- |
| 파일 크기 | 4,571,136바이트 |
| SHA-256 | `667b6c04e0952ebf39848ea59ab8f8457ae3136c3d115f268557d861eeade6ce` |

**위 값은 ISO 전체의 해시가 아닙니다.** 작업 자료는 ISO에서 추출한 파일로 제공되어, 원본 ISO 전체의 MD5·SHA-1·SHA-256은 아직 확인하지 못했습니다. 패치 프로그램이 ISO 내부 대상 파일을 검사하며, 지원하지 않는 수정본은 거부할 수 있습니다.

## 테스트 환경과 문제 제보

플레이 검수는 **2026년 10월 11일 당시 최신 xemu** 환경을 기준으로 했습니다. 마지막 글자 표시·안내 위치·상점 보정은 실행 코드와 데이터 검사를 마쳤으며 실제 게임 화면에서 추가 확인이 필요합니다.

**에뮬레이터 버전·설정·PC 환경·게임 데이터·저장 상태에 따라 그래픽 이상이나 멈춤이 발생할 수 있습니다.** 모든 환경의 동작이나 전체 구간의 무오류를 보장하지 않습니다.

에뮬레이터 설치·설정·일반 구동 문제는 [xemu 공식 문서](https://xemu.app/docs/)와 [호환 정보](https://xemu.app/#compatibility), 기존 오류 사례를 먼저 검색해 확인해 주세요.

번역 오류나 한글 깨짐·잘림을 발견하시면 **발생 장면, 스크린샷, 패치/xemu 버전**을 함께 알려주세요. 즐거운 플레이 후기와 응원도 큰 힘이 됩니다!

배포 파일의 SHA-256은 [SHA256SUMS.txt](SHA256SUMS.txt)에서 확인할 수 있습니다.
